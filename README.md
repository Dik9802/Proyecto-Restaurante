# Proyecto-Restaurante

A restaurant management system project built with Java.

## Overview

This is a comprehensive Java-based application designed for managing restaurant operations. The project includes tools for order management, inventory tracking, and customer service administration.

## Project Details

- **Language**: Java
- **Build System**: Apache Ant
- **IDE**: NetBeans (nbproject structure)
- **Repository Created**: November 22, 2018
- **Last Updated**: March 17, 2023
